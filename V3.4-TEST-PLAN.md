# V3.4 Test Plan

## Unit tests
- [ ] Planner → coder → parallel reviewer/debugger → planner sequence.
- [ ] Reviewer and debugger overlap in time.
- [ ] Missing or incomplete profiles are rejected.
- [ ] Tool registry permits read-only and blocks execution/legacy stage-all commit.
- [ ] Cancellation propagates and does not get swallowed as an agent error.

## Android / persistence
- [ ] `:app:testDebugUnitTest` passes.
- [ ] `:app:assembleDebug` succeeds.
- [ ] Room migration 1→2 preserves prior data and creates agent tables.
- [ ] Agent traces and run totals survive app restart.
- [ ] Profile API keys are encrypted and decrypt after process restart.
- [ ] Invalidated Keystore key is handled with a clear reconfiguration path.

## Provider and orchestration
- [ ] Configure different providers/models for all four roles.
- [ ] Verify tool-call round trips on OpenAI-compatible provider.
- [ ] Verify tool-call round trips on Anthropic-compatible provider.
- [ ] Verify provider-specific tool-call ID and JSON argument handling.
- [ ] Verify reviewer/debugger can run concurrently without UI corruption.
- [ ] Verify cancellation during parallel review cancels both agents.

## Approval and security
- [ ] Read-only tools execute without approval.
- [ ] File write proposal pauses the run and requires explicit approval.
- [ ] Rejected proposal is returned as a tool result and is not executed.
- [ ] Pull/push/workflow proposals require approval.
- [ ] Legacy stage-all commit and command execution are blocked.
- [ ] Project path outside app-private workspace is rejected.
- [ ] Untrusted file and web content cannot override agent instructions.

## Accounting
- [ ] Trace records include role, event, timing and estimated token counts.
- [ ] Run totals persist in Room.
- [ ] UI labels token counts as estimates, not provider billing usage.


## V3.4.1 chat-first UI checks

1. Fresh launch opens Chat, not Team, Projects, Git, Research, or Settings.
2. Empty Chat shows a welcome prompt and the composer at the bottom.
3. The composer remains visible while the conversation history scrolls.
4. Send is disabled until a model ID and API key are configured.
5. The setup link opens Settings; saving provider configuration returns to Chat through bottom navigation.
6. Projects and Team open from the bottom navigation.
7. More opens Git, Research, and Settings.
8. Approval cards, Continue agent, and Undo remain reachable in the Chat conversation.
9. Switching tabs and returning to Chat preserves the current in-memory conversation state.
