# V3.0 verification checklist

## Build/CI
- [ ] Gradle sync succeeds with JDK 17.
- [ ] KSP generates Room implementation and schema.
- [ ] `:app:testDebugUnitTest` passes.
- [ ] `:app:assembleDebug` succeeds.
- [ ] Install and launch on Android API 26+ device/emulator.

## Project storage
- [ ] Create project with ordinary name.
- [ ] Reject blank project name.
- [ ] Confirm each project has a unique folder under app-private workspace.
- [ ] Confirm projects persist after process restart.

## Session persistence APIs
- [ ] Create a session under a project.
- [ ] Append USER, ASSISTANT and TOOL messages.
- [ ] Observe messages in chronological order.
- [ ] Clear messages and verify session metadata remains.

## Provider/orchestration
- [ ] Existing OpenAI-compatible provider flow works.
- [ ] Existing Anthropic-compatible provider flow works.
- [ ] Provider registry resolves configured protocol.
- [ ] Tool registry distinguishes read-only, approval-required and blocked tools.
- [ ] Orchestrator stops at configured round limit.

## Regression/security
- [ ] Existing file write approval and hash recheck still work.
- [ ] Existing Git approval flows still work.
- [ ] Existing web retrieval protections still work.
- [ ] Verify API keys are not stored in Room or message history.
