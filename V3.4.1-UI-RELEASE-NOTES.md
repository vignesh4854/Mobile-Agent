# V3.4.1 UI Update

This update reorganizes the app around a chat-first mobile experience.

- Chat is the default launch screen.
- The message composer stays anchored above the bottom navigation while the conversation scrolls.
- Provider setup and integrations are moved into More → Settings.
- Projects and Team are directly accessible from the bottom navigation.
- Git and Research are accessible from More.
- Existing chat, approval, undo, Git, research, project, and multi-agent screens are retained.

This is a source update. It has not been compiled with Android Gradle or tested on a device in this environment. Run the repository GitHub Actions workflow and perform the manual UI checks in the test plan before installing.
