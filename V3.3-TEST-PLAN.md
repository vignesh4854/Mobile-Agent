# V3.3 Test Plan

## Unit tests
- [ ] Git operation approval is one-shot.
- [ ] Approval is bound to operation type and proposal parameters.
- [ ] Rejected proposals cannot be approved.

## Local repository integration
- [ ] Stage only one selected file; other modifications remain unstaged.
- [ ] Unstage selected file without changing its working-tree content.
- [ ] Staged diff shows index changes only.
- [ ] Unstaged diff shows working-tree changes only.
- [ ] Commit creates a commit containing only staged paths.
- [ ] Commit refuses when index is empty.
- [ ] Commit refuses when merge conflicts exist.
    - [ ] Commit refuses if staged path set changes after confirmation.
    - [ ] Pull refuses when working tree is dirty.
- [ ] Checkout refuses when working tree is dirty.
- [ ] Pull reports conflict paths.
- [ ] Push reports rejected/non-fast-forward remote updates.

## UI and Android
- [ ] `:app:testDebugUnitTest` passes.
- [ ] `:app:assembleDebug` succeeds.
- [ ] Compose state updates are performed on main dispatcher.
- [ ] Confirmation dialogs appear for commit/pull/push/checkout.
- [ ] Canceling a dialog does not perform the operation.
- [ ] Token is not persisted and is cleared when screen leaves composition.

## Security
- [ ] Absolute paths and `..` traversal are rejected.
- [ ] `.` stage-all, `.git` metadata and wildcard pathspecs are rejected.
- [ ] Verify JGit pathspec behavior for unusual filenames.
- [ ] Confirm approval cannot be replayed.
- [ ] Confirm push does not use push-all.
