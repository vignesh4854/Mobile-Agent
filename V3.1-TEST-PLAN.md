# V3.1 Test Plan

## Automated unit tests
- [ ] Parse valid single-hunk unified diff.
- [ ] Reject absolute and parent-traversal paths.
- [ ] Reject malformed hunk counts.
- [ ] Diff engine marks additions and removals correctly.
- [ ] Preview does not mutate original files.
- [ ] Approved patch updates target content.
- [ ] Undo restores original content.
- [ ] Stale preview is rejected if file changes before approval.

## Android integration
- [ ] `:app:testDebugUnitTest` passes.
- [ ] `:app:assembleDebug` succeeds.
- [ ] PatchReviewCard renders on API 26+.
- [ ] Host screen wires approve/reject callbacks.
- [ ] Verify backup retention and app-private path behavior.

## Security and edge cases
- [ ] Symlink and sensitive paths are rejected.
- [ ] Duplicate context does not silently apply to the wrong location.
- [ ] Oversized patch/file/diff is rejected.
- [ ] Undo refuses to overwrite a file modified after patch application.
- [ ] Simulated write failure leaves original content recoverable.
