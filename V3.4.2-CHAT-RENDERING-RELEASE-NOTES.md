# V3.4.2 — Chat rendering and copy

## Changes
- Replaced the line-based Markdown display with Markwon/CommonMark rendering.
- Added Markdown table and strikethrough support.
- Added a Copy response action to assistant messages, streaming output, and multi-agent final output.
- Enabled native Android text selection for rendered response text, including long-press selection/copy.
- Kept a shared `MarkdownText` component so chat and Team output use the same renderer.

## Limitations / verification
- Code blocks use Markwon's standard rendering; this release does not add language-specific syntax highlighting or a separate copy button per code block.
- Wide content is placed in a horizontally scrollable container.
- Gradle compilation, dependency resolution, automated tests, and physical-device behaviour must still be verified by the Android CI workflow/device. Do not treat source edits as proof of a successful build.
