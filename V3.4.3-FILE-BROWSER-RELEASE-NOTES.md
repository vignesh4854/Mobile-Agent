# V3.4.3 — Project File Browser and Export

## Project screen
- Open a project from the Projects tab to browse its workspace files and folders.
- Navigate into folders, return to the parent folder, or jump to the project root.
- Preview text files up to 256 KB.
- Export individual files using Android's system Create Document picker, allowing the user to choose Downloads, Documents, Drive, or another supported destination.

## Safety
- Browsing is restricted to the app-private `filesDir/workspace/projects` tree.
- Symbolic links are excluded.
- `.git` and `.agent-backups` directories are hidden.
- Files matching the existing sensitive-file policy are hidden.
- File preview is size-limited; export uses Android's document picker.

## Verification
- Source changes and ZIP archive integrity checked.
- Android Gradle compilation and physical-device testing have not been run because this environment has no Gradle executable or project Gradle wrapper.
