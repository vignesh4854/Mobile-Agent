# V3.4 Release Notes

V3.4 introduces the native multi-agent team panel with Planner, Coder, Reviewer and Debugger roles. Each role can use its own model provider configuration. Reviewer and Debugger run in parallel after the Coder handoff. All agents share project context and a central tool permission gateway.

Agent profiles are persisted with encrypted API keys. Execution traces and estimated token usage are stored in Room database version 2. Token counts are estimates because the current provider adapter does not parse provider-specific usage fields.

This is a source milestone, not a compiled or device-tested APK. Android Gradle build and device integration tests remain required.
